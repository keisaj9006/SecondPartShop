# SecondPart — Project Context

## 1. Product purpose

SecondPart is designed for the UK used/recycled vehicle-parts market.

The core problem is not "how do I display car-part listings?"

The core problem is:

> How does a buyer reliably obtain the correct used component for a specific vehicle from fragmented professional supply?

SecondPart therefore combines:
- marketplace inventory,
- vehicle context,
- compatibility evidence,
- reverse sourcing,
- protected transactions,
- seller operations.

## 2. Target users

### Buyers
- private vehicle owners
- enthusiasts
- people replacing a damaged/faulty component
- users who do not know technical part codes

### Trade buyers
- garages
- mechanics
- bodyshops
- future repeat B2B users

### Sellers
Primary strategic seller categories:
- breakers/recyclers
- ATFs
- garages
- automotive businesses
- professional high-inventory sellers

Private sellers may exist in the product, but professional marketplace liquidity remains the launch priority.

## 3. Core user promise

A buyer should be able to say:

> "I need a part for my car"

and the product should progressively resolve:
- the vehicle,
- the part,
- critical variant ambiguity,
- compatible inventory,
- safe purchase.

The product should hide technical complexity until it is genuinely needed.

## 4. Buyer journey

Ideal flow:

1. select or identify vehicle,
2. save it to Garage,
3. search by natural-language part name, OE/OEM number, category or supported identifier,
4. rank or filter by fitment confidence,
5. inspect "why it fits",
6. if inventory is insufficient, use Find My Part with vehicle context prefilled,
7. compare structured seller offers,
8. protected checkout,
9. tracked fulfilment,
10. receive/install,
11. review seller and confirm fit,
12. feed successful/failed fit data back into marketplace intelligence.

## 5. Seller journey

Seller should be able to:
- create/maintain seller identity,
- complete payout onboarding,
- create or import inventory,
- associate donor/fitment data,
- respond to relevant demand,
- fulfil protected orders,
- maintain operational reputation.

The long-term seller promise is:

> SecondPart should create incremental sales without creating another full-time inventory administration job.

## 6. Compatibility philosophy

A used component is a physical part instance, not only a catalogue SKU.

Relevant concepts include:
- buyer vehicle
- vehicle variant
- donor vehicle
- generic part type
- physical part instance
- OE/OEM numbers
- compatibility assertions
- compatibility evidence
- seller inventory

Current implementation must be evolved carefully rather than replaced wholesale.

## 7. Search philosophy

Search must support:
- part name
- category
- OE/OEM / part number
- brand/keywords where useful
- vehicle context

Compatibility and relevance should outrank paid placement.

## 8. Find My Part

Find My Part should ultimately act as an extension of search.

It should:
- reuse known vehicle context,
- collect only missing details,
- protect buyer contact information,
- target likely sellers,
- collect normalized quotes,
- produce structured comparison.

It should not devolve into uncontrolled phone/SMS spam.

## 9. Trust / protection

SecondPart should be more accountable than lead-generation networks.

Important trust surfaces:
- seller verification
- seller type
- buyer protection
- payment-provider-backed checkout
- order events
- delivery/receipt evidence
- returns/disputes
- warranty normalization
- reviews
- Verified Fit
- seller performance metrics

## 10. Marketplace liquidity

Engineering readiness and marketplace liquidity are separate.

A technically complete app with six listings is not a launch-ready marketplace.

Supply quality metrics matter:
- active inventory
- seller activity
- breaker/ATF coverage
- search fill rate
- request response rate
- inventory freshness
- wrong-fit rate
- order fulfilment quality

## 11. Growth strategy

Current launch strategy is supply-first:
- Founding Seller / Recycler Programme
- breaker/ATF outreach
- high-inventory seller onboarding
- inventory import
- Find My Part
- closed beta
- public launch only after meaningful liquidity

Broad paid buyer acquisition comes later.

## 12. Strategic priority order

1. correct part
2. available part
3. trusted transaction
4. reliable fulfilment
5. low price
